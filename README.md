# Lunana

A native plugin suite for the **Omarchy** (Quattro) shell that re-hosts
[inir](https://github.com/snowarch/inir)'s full UI — ii, iRiS, and Waffle
families — as Omarchy plugins inside the single `omarchy-shell` process,
swapped via `~/.config/omarchy/shell.json` and cleanly interchangeable with
stock.

> **Status: full-parity program (plan.md).** All iNiR surfaces ship as
> `lunana.*` hosts over a mechanically vendored iNiR tree (`vendor/`, never
> hand-edited — regenerated by `scripts/vendor.py` from the inir checkout).
> Hyprland feature gaps are fixed in the inir source, then re-vendored.

## How it works

Omarchy hosts plugins by `manifest.json` (`kinds`: `bar`, `overlay`,
`service`, …) inside one shell process. Lunana ships `lunana.*` plugins:

- **Bar hosts** (`kind: bar`) mount the vendored family bar directly —
  `lunana.bar` (ii) and `lunana.bar-waffle` (Waffle). Selected via
  `shell.json → bar.id`; empty/absent falls back to `omarchy.bar`.
- **Overlays** (`kind: overlay`) wrap the vendored surface (own windows or a
  host-provided `PanelWindow`) and expose `open/close/toggle/opened` +
  `ShellIpc`, summoned by `omarchy-shell shell toggle <id>`.
- **Services** (`kind: service`) are resident mounts (background, dock, lock,
  OSD, notifications, mascot, …) that show on the vendored tree's own state.

`lunana.family/family-cycle` switches the live set — `ii ↔ waffle ↔ iris ↔
stock` — enabling exactly one family's plugins (each family owns its
dock/lock/background/OSD; only `lunana.state` is shared). Coherence guards in
the bar and dock hosts yield the top edge to the iRiS island/dock while the
iris family is active.

The suite runs as your user, never calls pacman/sudo, never touches
`/usr/share/omarchy`, backs up `shell.json`, and writes it atomically.

## Try the swap

```bash
# validate + preview (writes nothing)
./scripts/lunana-suite install --dry-run

# swap the live bar to lunana (prompts first; hot-reloads)
./scripts/lunana-suite install

# cycle families: ii -> waffle -> iris -> stock
./lunana.family/family-cycle cycle

# after editing QML: re-copy + restart the shell (bar changes need a restart)
./scripts/lunana-suite sync

# check state
./scripts/lunana-suite status

# restore the stock Omarchy bar
./scripts/lunana-suite uninstall
```

## Keybinds

Installed additively into `~/.config/hypr/bindings.lua` (`-- >>> lunana >>>`
block, backed up, removed on uninstall). Omarchy's own binds stay untouched.

| Bind | Surface |
|---|---|
| `SUPER + SPACE` | Overview (grid + search + calculator) |
| `SUPER + SHIFT + L` / `R` | Left / right sidebar |
| `SUPER + SHIFT + C` | Control center |
| `SUPER + SLASH` | Cheatsheet |
| `SUPER + SHIFT + S` | Region snip (screenshot/OCR/record) |
| `SUPER + SHIFT + I` | iRiS island |
| `SUPER + SHIFT + W` | Family switch |

## Families and surfaces

- **ii**: bar (classic/islands/scenic/frame/pill/m3), dock, overview, sidebar
  left (AI chat, YT Music, translator, anime, Wallhaven, news, tools), sidebar
  right, control center, background, lock, OSD, cheatsheet, notifications,
  wallpaper launcher/selector, region selector, session screen, mascot,
  alt switcher, tiling overlay, close confirm, settings.
- **iRiS**: island, background/afterglow, palette, control grid, orbit +
  workspace strip, stage, dock, edit mode, lock, notifications, settings.
- **Waffle**: taskbar, start menu, action/notification centers, backdrop,
  background, lock, OSD, settings.

Theme defaults to Omarchy tokens; Material You (wallpaper-derived) is an
opt-in via `lunana.state`'s `themeSource` (`shell.json → lunana` subtree).

## Verification (nested harness, never the live session)

```bash
scripts/test/nested-hypr up [--size WxH]      # nested Hyprland + fixture $HOME
scripts/test/nested-hypr install               # suite install into the fixture
scripts/test/nested-hypr drive <ipc...>        # toggle surfaces
scripts/test/nested-hypr shot <name>           # grim capture for review
scripts/test/nested-hypr logs                  # QML errors/warnings (must be clean)
scripts/test/nested-hypr down
```

Per surface: loads with no new QML errors, toggle opens/closes, live data is
correct, capture saved. `python3 tests/test_manifests.py` keeps manifests,
vendor closures, family cycling, and the suite green.

## Layout

- `lunana.*/` — plugin hosts (one dir per surface; entry QML + manifest).
- `vendor/` — mechanical copy of the inir tree (`scripts/vendor.py` output).
- `scripts/lunana-suite` — transactional install/swap tool.
- `lunana.family/family-cycle` — family switcher.
- `scripts/test/nested-hypr` — nested-Hyprland test harness.
- `scripts/hypr/lunana.conf` — iNiR-owned layerrules (installed/removed by suite).
- `contracts/host-facade-v1.json` — pinned host contract (Omarchy Quattro 4.0.0.alpha).
- `PORTING.md` — living parity checklist. `plan.md` — the full program.
